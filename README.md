# 象棋小棋聖 V2.9.3 ｜ 象棋開局譜全功能版

## 🌟 版本特色與新增功能

### 1. 先後手記譜功能 (Move Recording & Auto Flip)
- **先手記譜 / 後手記譜**：點擊「先手記譜」執紅、「後手記譜」自動翻轉棋盤為黑方視角。
- **走子規則檢核**：嚴格依循象棋走子規則（九宮、士象巡河、馬腿撇腳、炮架吃子、照面殺）。
- **即時記錄列**：顯示目前記譜步數、紅黑走子提示、即時推薦最佳下一步、悔棋、清空與結束記譜。

### 2. 匯入棋譜與多格式儲存 (Import & Storage)
- **多格式自動辨識匯入**：
  - 中文記譜（如「1. 炮二平五 馬８進７ 2. 馬二進三 車９平８」）
  - 東萍 DhtmlXQ 標籤（[DhtmlXQ]...[/DhtmlXQ]，支援 [DhtmlXQ_movelist] 與 [DhtmlXQ_binit]）
  - WXF 英文記譜
  - ICCS 座標記譜
  - PGN 棋譜
  - FEN 盤面代碼
  - JSON 結構化資料
- **批次匯入多盤**：支援一次貼上多盤東萍標籤或多段記譜，自動分割並逐盤解析匯入。
- **本地 + 伺服器雙重儲存**：儲存時同步存入本機 IndexedDB / localStorage，並非同步 POST 存入後端資料庫 xiangqi-db.json。
- **已儲存棋譜管理**：支援載入播放、多格式匯出複製、單盤刪除與一鍵清空。

### 3. 自動開局分類與開局樹狀圖 (Opening Classification & Tree Diagram)
- **30+ 種經典開局分類**：涵蓋中炮對屏風馬、順手砲、列手砲、半途列砲、反宮馬、單提馬、仙人指路、飛相局、起馬局、過宮炮、仕角炮、金鉤炮、邊兵局等。
- **🌳 開局分類樹狀圖**：樹狀分支折疊展開、分類圖示、分支線條（├─、└─）、子項目數量統計，點擊即可直達開局清單。

### 4. 開局分類關聯 YouTube 影片 (YouTube Video Integration)
- **專屬 YouTube 播放清單與教學影片**：每個開局均內建「▶ 教學影片」或「▶ 專題清單」連結。
- **🔍 搜尋開局影片**：記譜或載入棋譜後，點擊可自動比對走步並推薦對應的 YouTube 教學影片。

### 5. Pikafish / 雲庫即時分析與最佳下一步推薦 (AI Engine & Best Moves)
- **AI 局勢評估條**：即時計算局勢領先分數與兵數差值（如「紅方大優 +1.50」）。
- **前三大最佳著法推薦**：清晰展示 ★1、2、3 名推薦著法，點擊即可直接走子或在棋盤上試走。
- **雲庫 / Pikafish 級深度評估**：自動對接雲庫與本地 Minimax 引擎雙重驗證。

### 6. 語音評估優劣勢與播報 (Web Speech Synthesis)
- **🔊 語音評估局勢**：一鍵朗讀目前局勢（如「紅方勝勢，領先 2.5 個兵。輪到黑方走子。推薦最佳著法：炮二平五」）。
- **走子自動朗讀**：每步走子自動用語音朗讀中文著名（如「炮二平五」）與將軍提示。
- **設定開關**：可在「設定」分頁自由開啟或關閉各項語音功能。

### 7. 東萍大師棋譜同步中心 (Grandmaster Sync Hub)
- **25+ 位特級大師快速同步**：王天一、許銀川、呂欽、胡榮華、柳大華、曹岩磊、趙國榮、汪洋、趙鑫鑫、孟繁睿、楊官璘、蔣川、鄭惟桐等一鍵同步。
- **自訂棋手搜尋同步**：輸入任意棋手名稱，同步抓取最多 20 頁、100 盤。
- **即時進度條**：直觀顯示同步進度與狀態。
- **大師棋手庫與棋譜庫**：即時搜尋，每盤棋均有「▶ 原棋盤播放」按鈕，點擊立即載入互動棋盤！
