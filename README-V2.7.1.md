# 象棋小棋聖 V2.7.1

## 一鍵啟動
雙擊 `一鍵啟動V2.7.1.bat`

它會：
1. 檢查 Node.js / npm
2. 自動關閉目前占用 3000 埠的舊 Node 服務
3. 安裝 npm 套件（第一次）
4. 啟動 V2.7.1
5. 用 `/api/health` 確認版本真的為 2.7.1
6. 自動開啟瀏覽器

## 如何確認版本
瀏覽：
- http://localhost:3000/api/health
- 首頁右上角會顯示 `象棋小棋聖 V2.7.1`

## 停止
雙擊 `停止網站V2.7.1.bat`

## 注意
停止腳本會終止目前占用 TCP 3000 的程序；如果電腦上另有其他程式使用 3000 埠，請先確認。
